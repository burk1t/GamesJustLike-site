
# Проверка сценариев GamesJustLike

## 1. Успешный запрос
Действие: покупатель открывает каталог.
Запрос: GET /api/games
Условие: сервер доступен, параметры корректны.
Ответ: 200 OK.
Результат: браузер отображает список игр.

## 2. Неверные данные
Действие: пользователь отправляет некорректные параметры поиска.
Запрос: GET /api/games?min_price=abc
Ответ: 400 Bad Request.
Результат: браузер показывает сообщение о неправильных параметрах.

## 3. Отсутствие авторизации
Действие: гость пытается открыть личные предпочтения.
Запрос: GET /api/preferences
Ответ: 401 Unauthorized.
Результат: браузер предлагает войти в аккаунт.

## 4. Попытка доступа к чужому заказу
Действие: покупатель пытается открыть заказ другого пользователя.
Запрос: GET /api/orders/15
Условие: заказ существует, но принадлежит другому аккаунту.
Ответ: 403 Forbidden.
Результат: браузер показывает сообщение об отсутствии доступа.

## 5. Отсутствие товара
Действие: покупатель открывает несуществующую игру.
Запрос: GET /api/games/9999
Ответ: 404 Not Found.
Результат: браузер отображает сообщение «Игра не найдена».

## 6. Отсутствие истории предпочтений
Действие: новый покупатель входит на сайт.
Запрос: GET /api/recommendations
Условие: история событий и индивидуальные предпочтения отсутствуют.
Ответ: 200 OK.
Результат: сервер формирует стартовую подборку популярных и новых игр.
Браузер отображает стартовые рекомендации.

## Общий вывод
Шесть сценариев показывают обработку успешных запросов, неправильных данных, отсутствия авторизации, нарушения доступа, отсутствия товара и пустой истории предпочтений.
Ошибки обрабатываются сервером, а клиентская часть отображает соответствующие сообщения или предлагает повторить действие.
