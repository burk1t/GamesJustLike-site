# ОТЧЁТ ПО ПРАКТИЧЕСКОЙ РАБОТЕ

## Проект GamesJustLike

**Тема:** Проектирование архитектуры веб-сайта GamesJustLike.

**Цель работы:** Разработать архитектурное представление веб-сайта для поиска компьютерных игр, просмотра информации о них, фильтрации и сравнения цен.

## 1. Описание проекта

GamesJustLike — веб-сайт, предназначенный для поиска и изучения компьютерных игр. Пользователь может просматривать каталог, искать игры по названию, выбирать категории, изучать характеристики и сравнивать стоимость.

Основные предполагаемые возможности:
- просмотр каталога игр;
- поиск и фильтрация;
- просмотр подробной информации;
- регистрация и авторизация;
- сравнение цен;
- работа с корзиной;
- оформление заказов;
- выбор валюты.

## 2. Архитектура проекта

Проект разделён на несколько логических частей:

- **Клиентская часть** — пользовательский интерфейс и взаимодействие с сайтом.
- **Серверная часть** — обработка запросов и бизнес-логика.
- **База данных** — хранение информации о пользователях, играх, категориях, корзинах и заказах.
- **SQL-запросы** — получение, фильтрация и обработка данных.

## 4. База данных SQLite

Для хранения информации спроектирована реляционная база данных GamesJustLike.db.

В структуре предусмотрено 18 таблиц:

1. roles
2. users
3. sessions
4. categories
5. games
6. preferences
7. events
8. user_preferences
9. groups
10. user_groups
11. group_preferences
12. group_categories
13. game_preferences
14. game_relations
15. carts
16. cart_items
17. orders
18. order_items

Также предусмотрено 6 индексов для ускорения поиска и обработки данных.

## 5. SQL-запросы

Подготовлен набор из 10 запросов для основных операций:

1. Поиск пользователя по логину.
2. Получение списка игр.
3. Поиск игры по названию.
4. Фильтрация игр по категории.
5. Фильтрация по диапазону цен.
6. Сортировка игр по рейтингу.
7. Получение подробной информации об игре.
8. Просмотр корзины пользователя.
9. Получение истории заказов.
10. Поиск похожих игр.

## 6. Диаграммы последовательности

Предусмотрены диаграммы для следующих процессов:

1. Поиск и фильтрация игр.
2. Просмотр информации об игре.
3. Регистрация пользователя.
4. Авторизация пользователя.
5. Сравнение цен.
6. Добавление игры в корзину.
7. Оформление заказа.
8. Выбор валюты.

Диаграммы показывают взаимодействие пользователя, интерфейса, контроллеров и базы данных.

## 7. Используемые инструменты

- SQLite — система управления базой данных.
- SQLiteStudio — создание и выполнение SQL-запросов.
- Mermaid — описание диаграмм последовательности.
- XAMPP — локальная среда разработки.
- PHP, HTML, CSS и JavaScript — технологии веб-разработки.

## 8. Проверка и тестирование

Для проверки базы данных предусмотрены следующие операции:

- проверка целостности командой PRAGMA integrity_check;
- проверка внешних ключей командой PRAGMA foreign_key_check;
- подсчёт записей в таблицах;
- проверка связей между играми и категориями;
- выполнение подготовленных SQL-запросов.

Фактические результаты проверок необходимо зафиксировать после выполнения тестов.

## 9. Заключение

В ходе практической работы подготовлена архитектурная структура проекта GamesJustLike, спроектирована структура реляционной базы данных SQLite, подготовлены SQL-запросы и диаграммы последовательности для основных пользовательских сценариев.

Полученные материалы формируют основу для дальнейшей разработки, проверки и интеграции клиентской и серверной частей веб-сайта.

**Статус:** архитектурные материалы подготовлены; работоспособность всех функций сайта требует отдельной проверки.
