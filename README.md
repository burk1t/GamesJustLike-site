# GameJustLike

**Каталог видеоигр с фильтрами и коллекция браузерных мини-игр.**

🌐 **Опубликованный сайт:** https://burk1t.github.io/GamesJustLike-site/

## Страницы

- **`index.html`** — каталог игр с поиском, фильтрами и сравнением.
- **`games.html`** — список онлайн-игр.
- **`snake.html`** — игра «Змейка».
- **`rps.html`** — игра «Камень-ножницы-бумага».

## Технологии

- HTML5
- CSS3 (Grid, Flexbox, медиазапросы)
- JavaScript (фильтрация, поиск, localStorage, игры)

## Локальный запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8000
```

После запуска открыть в браузере:

http://localhost:8000
